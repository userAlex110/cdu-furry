- 研究日期：2026-11-18。来源表：`docs/backend-selection-sources.md`。离线核算：`python3 docs/backend-metered-cost.py`，结果写到同目录的 `docs/backend-metered-cost-results.json`。

## 结论（替换上一版）

上一版把「继续评估微信云开发 / CloudBase 国内付费入门」写成默认方向。那个方向把维护方便放在现金成本前面，候选也主要停在阿里云和 CloudBase。它不符合 Issue 3 更新后的目标，**不再作为本文件的建议**。

现在优先验证的是 **uniCloud 支付宝云的纯按量空间**。官方价格页写明支付宝云支持纯按量，同时有云函数、文档数据库和云存储。原生微信小程序可以走 HTTPS API，不需要改成 uni-app，也不需要改成支付宝小程序。

这仍然只是验证顺序，不是生产选型。数据库和身份都不能写成与现行 EMAS 直接兼容。

若这 200 元可退保证金不能接受，或后面的验证清单有一项不通过，再按文末顺序看别的组合。那些组合里，数字更低也不等于可以上生产。

## 2. 本轮重新打开后可以引用的官方事实

价格页 https://doc.dcloud.net.cn/uniCloud/price.html ，页底「上次更新: 2026/10/9 10:30:17」：

- 【事实】支付宝云支持「基础套餐 + 超限按量」和「纯按量」。对比表写腾讯云纯按量「不支持」，支付宝云和阿里云「支持」。uniCloud 的阿里云空间已随 EMAS 停止新建，不能把这格当成还能新开的阿里云空间。
- 【事实】纯按量单价：函数 0.000110592 元/GBs、0.0133 元/万次、出网 0.8 元/GB；数据库 0.07 元/GB/天、读 0.015 元/万 RU、写 0.05 元/万 WU；存储 0.004 元/GB/天、上传和下载各 0.01 元/万次、CDN 0.18 元/GB、回源 0.15 元/GB。
- 【事实】按量需要预存余额，按前一日用量出账。保证金 200 元，不再使用按量空间后可以退。保证金不能开发票，页面把它和余额分成两项。因此 200 元不是月费，也不能拿来抵扣余额。
- 【事实】另有免费空间，默认一个月，要主动续期；基础版套餐 4.5 元/月。免费空间开超限按量也要保证金和余额。本轮不用免费配额来证明低成本。
- 【事实】开通前，DCloud 实名身份要已有对应支付宝账号。页面写暂不支持民办非企业单位。成大主体是否受这一句影响，【待验证】。
- 【事实】同一页的资源限制表：支付宝云 HTTP 触发最大超时 180 秒，定时任务单次最大 3 小时，数据库单次请求超时写的是 5–300 秒。同一页后部仍写支付宝云数据库是自研、兼容 MongoDB 协议、`_id` 为字符串且没有 ObjectId；另有一句写 2026-03-25 之后新建空间已切回 MongoDB。两处同时存在，所以不能宣称和现行 EMAS 库直接兼容。
- 【事实】对比表写支付宝云「HTTPS 证书托管」仅付费服务空间支持。纯按量算不算这里的付费服务空间，【待验证】。

HTTP 页 https://doc.dcloud.net.cn/uniCloud/http.html ：非 uni-app 系统通过 HTTP URL 连接 uniCloud。支付宝云最多绑定 3 个自定义域名，绑定要求域名在阿里云接入备案。默认域名的共享限流和鉴权要自己做。这没有证明小程序合法域名、ICP 和真机请求已经通过。

函数页 https://doc.dcloud.net.cn/uniCloud/cf-functions.html ：单个云函数上传包 10MB（含 `node_modules`）；支付宝云可在云端安装 npm，此时不占这 10MB。已知 `node-canvas` 因缺少系统库无法在云端编译。支付宝云默认内存 512MB；非定时超时 180 秒，定时任务在开启异步超时后最长 3 小时。页面没有把「最小可配 128MB」单独写成支付宝云的承诺，内存能否调到测算用的 256MB，【待验证】。支付宝云与阿里云暂不可用相对路径读文件。

函数计算 FC 计费页 https://help.aliyun.com/zh/functioncompute/billing-overview-of-fc ：单小时内调用次数大于 0 或持续占有计算资源的函数，该小时折算不足 0.01 元时按 0.01 元计。阶梯 1 标价 0.00011 元/CU；页面上的 0.000088 折扣列写活动到 2026-08-27，今天已过，不用折扣价。这是 FC 的小时最低消费，不是 EMAS 下线公告里的条款。EMAS 公告 https://help.aliyun.com/zh/document_detail/2584338.html （更新 2026-10-26）写 2026-11-01 起停止新空间，2027-09-30 停服，且只涉及该产品。

## 3. 三组假设和已定价核心费用

下列负载是假设，不是成大的访问统计，也不是性能测试。每月 30 天。容量用十进制 GB（10^9 字节）。内存用 GiB。COS 流量按它自己的 1024 进制。脚本把未知项写成 `null`，不参与加总。

| 假设 | 空闲保留 | 轻量 | 常规 |
| --- | ---: | ---: | ---: |
| 用户访问次数/月 | 0 | 1,000 | 10,000 |
| 业务 API（每次访问 8 个） | 0 | 8,000 | 80,000 |
| 逻辑写入/月 | 0 | 200 | 2,000 |
| 原图处理张数/月 | 0 | 50 | 300 |
| 列表缩略图 | 每次访问 12 张，每张 80,000 字节 | 同左 | 同左 |
| 另开原图 | 0 张 | 20 张，每张 800,000 字节 | 200 张 |
| 每 5 分钟定时 | 8,640 次 | 8,640 次 | 8,640 次 |
| 月备份 | 4 次 | 4 次 | 4 次 |

函数时长假设：API 与定时 256MiB × 0.2 秒，图片 512MiB × 5 秒，备份 512MiB × 10 秒。数据库读按每次 API 4 次、定时 1 次，再加整库备份扫描。写按逻辑写入的 3 倍估算，这是参数，不是厂商承诺。本地脚本跑出的调用数和 GBs 为：空闲 8,644 次 / 452 GBs，轻量 16,694 次 / 977 GBs，常规 88,944 次 / 5,202 GBs。

图片在 uniCloud 模型里走 CDN：用户看到的字节 100% 计入 CDN，其中 20% 再计入回源；压缩函数拉取原图同时计入 CDN 和 100% 回源。这是两条不同的计费项。该模型不再另加一条 COS 直出。命中率 80% 是假设，不是测量值。

### 纯按量核心小计

2026-11-18 在本机执行 `python3 docs/backend-metered-cost.py`，断言通过。单位是元/月。每一格都是已定价核心，完整账单是「核心 + U」。U 包括日志、内容安全附加费、域名和证书的分摊、尚未定价的强制项。U 不是 0。

| 已定价项 | 空闲保留 | 轻量 1,000 次访问 | 常规 10,000 次访问 |
| --- | ---: | ---: | ---: |
| 函数计算和调用 | 0.0615 | 0.1303 | 0.6936 |
| API 响应出网 | 0.0000 | 0.0512 | 0.5120 |
| 数据库留存 | 0.1050 | 0.2100 | 0.6300 |
| 数据库读写 | 0.0862 | 0.2104 | 0.9624 |
| 对象留存 | 0.2400 | 0.6000 | 1.8000 |
| 对象请求 | 0.0000 | 0.0147 | 0.1457 |
| CDN | 0.0000 | 0.1829 | 1.8000 |
| CDN 回源 | 0.0000 | 0.0353 | 0.3288 |
| 核心小计 | 0.4927 + U | 1.4347 + U | 6.8726 + U |

空闲和轻量里显示成 0.0000 的格子，是四位小数四舍五入。空闲的对象请求实际约 0.000004 元，已经加进 0.4927。它不是免费项目。

0.49、1.43、6.87 元只覆盖上表这些已定价项。它们不是总账单，也不是「每月一定不到 10 元」的承诺。200 元保证金另计，不除以 12，不从余额里扣。

官方默认内存是 512MB。若 API 和定时都不能调到测算用的 256MiB，这两部分的 GBs 会翻倍。【推断】函数费大约增加：轻量 0.09 元、常规 0.49 元。核心小计仍要再加 U。这还不是实测。

只作预算演示：若以后核清并控制 U ≤ 2 元/月，三种负载的上界大约是 2.49、3.43、8.87 元。这 2 元是人为留下的余量，不是厂商报价。U 未核清时，不能宣布全包一定不到 10 元。CDN 若完全不命中，常规负载的 CDN 加回源会高于上表，10 元上限同样不能承诺。

免费空间加超限按量在同一脚本里的核心小计约为 0、0.02、3.96 元 + U。它要每月续期，开超限仍要保证金和余额。不把它当成长期线上方案。基础版 4.5 元/月是固定订阅，本轮不把它混进纯按量。

## 4. 还不能当成兼容的事项

价格和超时页不能代替移植测试。下面全部是【待验证】，在验证通过前保持失败状态。

| 项 | 为什么还不能算通过 |
| --- | --- |
| 时限 | HTTP 触发官方上限 180 秒，定时 3 小时。现行 `photoProcess.js` 的 `TOTAL_BUDGET_MS` 是 60 秒，和 180 秒同页并不等于图片依赖跑得完，也不等于微信客户端会一直等。 |
| 内存 | 默认 512MB。能否改成 256MB，以及 jimp 在该内存下会不会失败，没有运行记录。 |
| 包体 | 上传包 10MB。支付宝云可以云端装 npm，不占这 10MB。`functionsEMAS/timeTrigger/package.json` 依赖 jimp、opentype.js、svg2png-wasm、cos-nodejs-sdk-v5。云端安装是否成功、wasm 能否运行，未测。官方点名不能用的是 `node-canvas`，没有因此证明 jimp 可用。相对路径读文件在支付宝云上不可用。 |
| 图片处理 | 现逻辑在函数里画压缩图和水印，再走对象存储。uniCloud 的 CDN 价不能代替这条链路。待审图若必须私有，就不能为了 0.18 元/GB 把桶设成公开。 |
| HTTP 合法域名 | 自定义域名要阿里云备案接入，并配进小程序的 request、upload、download 合法域名。本轮没有配置，开发者工具里的「不校验合法域名」不算通过。 |
| code2session | 身份必须由自己的 HTTPS 函数用临时 code 向微信换 openid。AppSecret 只能留在服务端。本轮打开微信 code2Session 文档失败，不把失败写成「接口不存在」，也不把项目需要登录写成已经接通。 |
| 平台鉴权 | EMAS 的 `getCallerOpenid` 不会跟着 HTTP URL 一起出现。会话要自己签发和校验。 |
| 并发与权限 | 价格页写支付宝云最大实例数 600、QPS 2000。这是上限表，不是成大账号的配额，也不是已测并发。 |
| 数据库事务和分页 | 通用 API 文档里的 where、orderBy、skip、limit、事务，不能当成支付宝云已兼容现行聚合和分页。`getCatLocations.js` 使用聚合。高 offset 扫描是否可换成游标，未测。 |
| 管理员引导 | `userOp.js` 在用户数为 0 时把新用户写成 `manager: 99`。这是现行行为，禁止照搬。新后端要显式、可审计的管理员名单，禁止开放注册提权。 |

## 5. 其他组合：有价也不等于可生产

### 阿里云 FC 和 EMAS 不要混

【事实】EMAS 不能新建空间。FC 仍有按量页，但每活跃小时不足 0.01 元按 0.01 元。每 5 分钟一次的定时会覆盖 720 小时，若按「每个函数单独先落到 0.01 元」估算，仅定时函数就是 7.20 元/月。计费页同时写一小时内各函数的 CU 会累加后再出账。【待验证】0.01 元下限是按函数先取，还是按账号合计后再取。在这点确认前，不能承诺「FC + 独立 API + 5 分钟定时」稳定落在 5 元以内。把定时改成每小时一次也不会减少活跃小时。

FC 可以搭配表格存储 Tablestore 的按量 CU，预留可以设为 0。国内存储、按量写和公网下行的完整现价页本轮没有取到，保留为变量，不补 0。同分区事务存在，跨分区不等于现行 Mongo 事务。多元索引会带来预留读和额外存储，打开之后就不能再沿用「无预留」的公式。因此 SCF 或 FC 加 Tablestore 加 COS 可以继续补价，不能用残缺公式写成可生产推荐。

### SCF + 百度 BTS + COS

脚本给出的已定价核心约为 0.4673 + U、1.6227 + U、9.2051 + U 元/月。跨云部分同时计入：函数到 BTS 的请求出网、BTS 返回的 0.75 元/GB、COS 图片直出。用户看图的字节只在 COS 直出里，没有再加一次 CDN。常规负载离 10 元只剩大约 0.79 元给 U，不能保证。

BTS 的条件写、二级索引和跨行事务本轮没有证实。在这三项有证据之前，这组低价只是成本对照，不是生产推荐。不能靠取消用户投稿来换安全。

### 华为、火山、百度全家桶、Laf、Cloudflare

这些缺的是证据，不是淘汰结论。

- 华为 FunctionGraph 有按需价和每月免费额度，也有 2026-10-21 的函数 URL API。匿名访问、自定义域名和数据库长期价没有形成完整页，整套费用【未知】。
- 火山函数有按 vCPU 和内存的单价，弹性网关仍是邀测。未获准前，不能把「Serverless 网关托管 0 元」写成整套 0 元，因为同页 CLB 有小时价。同厂可休眠到 0 的文档库【未知】。
- 百度 CFC 和 BTS 有公开按量价，BOS 现价页没有取到完整数字。不用 2020 年案例价冒充现价，也不把 COS 的价格说成 BOS 的价格。
- Laf / Sealos 公有云按分配的 CPU 和内存计费。最小规格和能否休眠【未知】。没有停购公告，不写成不能用。
- Cloudflare Workers、D1、R2 有公开免费档。Free 档单次 CPU 时间很短，付费档有美元月租。支付方式和大陆访问【未知】。已接通不等于 R2 已开通。国内校园主路径先核国内按量，是因为备案、图片处理和数据位置还没测，不是因为禁用。

已有阿里云服务器的规格、地域和续费【未知】。自建的增量不能写成 0，续费也不能从总成本里拿掉。规格补齐之前，不把它升成首选。

## 6. 若以后批准迁移，代码上要改的边界

本轮不改这些文件。下面只标风险，供以后的单独议题使用。

- 客户端对 `mpServerless.db` 的 136 处调用要收到自己的 HTTPS API 后面。在那之前，页面仍依赖现行 EMAS。
- `functionsEMAS/unionOp/index.js` 的平台身份覆盖要换成 code2session 会话。客户端自报的 openid 不能采用。
- `userOp.js` 的首用户提权和 `updateRole` 规则不要原样复制。管理员名单放在服务端，并留下审计记录。
- `getCatLocations.js` 只检查登录。地图若保留，服务端要按已批准的地图权限决定是否返回精确点。
- `commentCheck.js` 只覆盖一段文本。图片和其余入口的内容安全配额【待验证】，附加费用进 U。
- `timeTrigger` 约每 5 分钟跑照片处理。任务要有幂等键。60 秒预算可以拆成多次短调用，不因此购买固定月租套餐。
- `catFace` 源码不在仓库内。它不参与本轮价格，也没有被取消。删哪些功能要你另作决定。

## 7. 下一步：等你批准的最小验证清单

在你点头之前，不做下列任何一项，也不创建云资源。

1. 确认主体能否开通支付宝云纯按量，以及 200 元保证金和独立余额是否可接受。保证金仍不计入月费。
2. 只建一个试用空间时，先确认 HTTP 触发能配到不少于 60 秒、内存是否可改、云端安装 jimp 与 wasm 是否成功。失败就停，不把 API 相似当成兼容。
