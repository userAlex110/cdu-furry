# 成大毛茸茸：后端选型建议

- 议题：https://github.com/userAlex110/cdu-furry/issues/3
- 代码基线：fork `master`，提交 `7ba22e5e947acba14732d97cab699e417f187f7f`（2026-11-14）
- 架构与成本的前一份记录在未合并的 https://github.com/userAlex110/cdu-furry/pull/1 （头提交 `fc2d723`，2026-11-18）。那份 PR 里的免费体验档 3 秒警告仍然成立，本文件不改那条分支。
- 研究日期：2026-11-18。来源表在 `docs/backend-selection-sources.md`。
- 标记：**【事实】** 能在源码或当天打开的官方页面上核对。**【推断】** 由这些材料推出，还不是实测。**【待验证】** 要控制台、PoC 或你补充的服务器信息才能定。
- 边界：本文是选型建议。它不是你已经批准的生产选型，也不是实施、购买、创建环境或删功能的授权。本轮没有登录控制台，没有创建或购买云资源，没有部署，没有改后端代码。

## 建议

继续评估的首选是国内付费入门的微信云开发 / 腾讯云 CloudBase，具体落在腾讯云国内站「个人版」这一档的公开能力表上：超时最大 900 秒、内存可改、每月 40,000 资源点。免费体验版的 3 秒超时只说明体验档跑不了现行 60 秒照片预算，不能用来淘汰国内付费个人版。

若实际购买入口是微信开发者工具里的「基础套餐」，月费和点数要单独读微信文档。那一页没有写 900 秒。基础套餐是否允许把超时改到 60 秒以上，标为待验证。

条件备选是已有的阿里云服务器上的轻量 API、数据库，加上腾讯云 COS 存图片。服务器规格、地域、到期日和续费未知。这些未知项补上之前，自建不能升成首选。

新建 EMAS Serverless 空间、把函数计算 FC 单独当成整套后端、以及新建 LeanCloud 应用，不进入候选。理由在第 3 节，都有当天打开的官方页面。

腾讯云同一页还写：免费体验的续期政策只适用于云开发控制台创建的体验版，微信体验版不适用。两边都写小程序发布后免费环境在第 15 天到期。

云函数配置文档 https://docs.cloudbase.net/cloud-function/function-configuration/config 写普通云函数默认 3 秒、可选 1–900 秒。这是配置项的默认值和上限，要和套餐能力表一起读。默认 3 秒不等于付费个人版的上限是 3 秒。

因此：

- PR #1 写「免费档 3 秒、256MB 不可改，对不上 `photoProcess` 的 60 秒预算」指的是腾讯云免费体验版。这句话不用改。
- 国内付费个人版按 140498 可以评估到 900 秒，不能因为免费档被划掉。
- 微信基础套餐的 19.9 元和 40,000 点是另一张价目。它和腾讯云个人版价格接近，但 900 秒尚未在微信计费页上出现。【待验证】在微信基础套餐的付费环境里把超时改到不少于 60 秒。验证之前，不把两个入口写成已经是同一种超时能力。
- 国际站套餐不作为国内项目的依据。本轮没有用国际站个人版的超时去判断国内个人版。

CloudBase 开发助手、Skills 或 MCP 认证只表示开发工具可登录。它不是环境、数据库或存储已经接入，也不是已经选定生产后端。

## 2. 现行代码里和选型有关的事实

下列路径都在 `master` 的 `7ba22e5` 上。统计日是 2026-11-18。

【事实】小程序通过 `@alicloud/mpserverless-sdk` 访问 EMAS。`miniprogram/` 里 `mpServerless.db` 出现在 50 个文件、共 136 处；`function.invoke` 出现在 8 个文件、共 38 处。`functionsEMAS/unionOp/` 有 37 个 js，`timeTrigger/` 有 6 个 js，`temp/` 有 7 个 js。线上形状是这两个常驻入口，另加仓库里没有源码的 `catFace`。迁到任何新后端都要重写这层，不是改一个配置项。本文件只给这个代码表面，不估人天。

【事实】`functionsEMAS/timeTrigger/index.js` 注释写约每 5 分钟跑 `countPhoto`、`getTempCOS`、`photoProcess`。`photoProcess.js` 的 `TOTAL_BUDGET_MS` 是 60000，这是代码自己的时间预算。`timeTrigger/Readme.md` 把函数超时记为 60 秒。三个任务用 `Promise.all` 共享同一次调用。预算 60 秒不等于平台必须提供 60 秒：照片处理可以拆成多次短任务或队列，逐张做完再标记。是否拆分要等超时能力验证之后决定。它不是升到标准版 199 元/月的理由。199 元档在 140498 上多出来的是 14 天回档、更大的点数配额等，那是另一项选择。

【事实】`functionsEMAS/unionOp/userOp.js` 的 `get` 分支在 `user` 集合计数为 0 时，把新建用户写成 `manager: 99`。这是现行实现，不是新后端推荐的权限设计。新后端的第一名管理员必须在部署时显式指定，并留下可审计记录，例如配置里的管理员 OpenID 名单或一次性引导码。禁止靠开放注册、靠「第一个访问的人」或靠客户端自报字段获得管理权。同文件的 `updateRole` 已要求调用者 `manager >= 99`，且不能修改自己的等级。那是现行补丁，不能当作新系统的开通方式。

【事实】`functionsEMAS/unionOp/index.js` 用 `_helper.js` 的 `getCallerOpenid` 覆盖客户端传来的 openid。`getCatLocations.js` 只拒绝没有 openid 的调用，随后把带经纬度的照片和常出没点返回给登录用户，函数体内没有检查 `mapAccess`。页面层的地图开关不能代替这个接口。新后端若保留地图，服务端要按已批准的地图权限决定是否返回精确点。这一点是待验收的鉴权项，不是已经设计完成的推荐方案。

【事实】`commentCheck.js` 用小程序 `access_token` 调用微信 `msg_sec_check`，检查的是文本。它没有覆盖全部用户内容。内容安全要覆盖哪些入口，等产品范围确定后再列验收，不在这里当成已经做完。

还没有验收、因此不能写成「只剩一个技术门槛」的事项：

- 鉴权：平台身份、管理员引导、地图接口。
- 数据库规则：客户端直连查询时，敏感集合不能被普通用户读出。
- 图片流程：上传签名、审核状态、压缩或水印、私有读取。
- 定时任务：周期、失败重试，以及照片任务是一次跑完还是拆开。

研究者笔记里曾把猫脸识别、喵友圈、榜单、徽章、领养等写成可以后做。那不是你已经批准的删功能清单。本文不裁剪现有页面范围。`catFace` 源码不在仓库内，所以它不能决定套餐档位；这只说明选型不依赖一个仓库外的函数，不表示该功能已被取消。

## 3. 候选

### 继续评估的首选：国内 CloudBase 付费入门

【事实】腾讯云国内个人版仍出现在 2026-11-10 的套餐表上，可以按该表评估，而不是按已停止新购的 EMAS。微信基础套餐仍出现在 2026-10-26 的计费说明上。文档型数据库、云函数和云存储与现行集合查询加两个函数入口属于同一类模型。【推断】迁移工作量短于先把原生小程序改成另一套前端框架，再改后端。工作量仍然是一次后端重写，见上一节的调用计数。

适用前提，全部成立才值得进入实施议题：

1. 【待验证】实际购买的那一档允许函数超时不少于 60 秒，或者照片处理已改成该档超时内能跑完的短任务。
2. 个人版没有 14 天回档。若选这一档，备份靠自己导出。这不自动要求购买 199 元标准版。
3. 管理员引导、数据库规则、图片链路和定时任务有单独验收，而不是假定套餐开通即可用。
4. 月预算按第 4 节的刊例或微信原价估算。19.9 元只作为活动价。
5. 创建环境和付费仍要你另行同意。

### 条件备选：已有阿里云服务器 + 自建 API + 数据库 + COS

【事实】Issue #3 记录你有阿里云服务器和域名。规格、地域、到期、续费、带宽和现有业务占用都未知。本轮没有登录那台服务器。COS 不在 EMAS 下线公告的范围内，公告页面 2026-10-26 写调整仅涉及 EMAS Serverless。

只有这些条件一起满足，才把自建改成首选或与 CloudBase 并列：

- 你补充非敏感的规格、地域、到期和续费，并确认容量不和原有业务冲突。
- 有固定的人能做系统补丁、备份、证书和监控，换届后仍能登录。
- 或者 CloudBase 付费档的超时与查询在 PoC 中达不到验收，而你也不选择标准版。

自建要自己完成微信 `code2session`、会话、内容安全、合法域名、HTTPS 和备案状态确认。图片建议继续走对象存储，避免从云服务器公网带宽直接下发原图。服务器续费不是零，只是本轮未知，不能写成增量成本为零。

### 不进入候选

【事实】EMAS Serverless：https://help.aliyun.com/zh/document_detail/2584338.html 更新于 2026-10-26。2026-11-01 起停止新空间和新购，续费叠加不超过 2027-08-31，2027-09-30 控制台和后端下线。公告写本次只涉及该产品。新建空间不能作为成大的后端。

【事实】函数计算 FC 仍是计算产品。EMAS 下线页面没有写 FC 停售。FC 不带本项目现在用的文档库、登录控制台和小程序 SDK。只买 FC 还要另搭数据库、身份、权限和图片，工作量接近自建。

【事实】LeanCloud：https://docs.leancloud.cn/sdk/announcements/sunset-announcement/ 写明 2026-01-12 起停止新用户注册和新建应用，2027-01-12 停止对外服务并销毁或匿名化数据。不能为新项目注册。

【事实】uniCloud 阿里云空间：https://ask.dcloud.net.cn/article/id-42719 发布于 2026-09-17，更新于 2026-11-17。与 EMAS 同步，2026-11-01 起不能新建阿里云空间，2027-09-30 停服。同一公告写可以创建支付宝云或腾讯云的 uniCloud 空间，并给出 uniCloud 腾讯云空间的比较，其中写套餐起步价 99 元/月、定时任务最长 900 秒。那是 uniCloud 的腾讯云空间价目，不是微信云开发个人版的 39.9 元或 19.9 元，也不是 140498 那张超时表。本仓库是微信原生小程序，不是 uni-app。【推断】为了使用 uniCloud 再换前端框架，不是这条原生代码更短的路径。DCloud 在公告里称微信云开发不会下线，那是 DCloud 的表述，不是腾讯云的停服承诺。

### 有条件比较、但不作为当前首选

**Laf / Sealos。** 【事实】当前运行路径是 EMAS，不是 Laf。`README.md`、`miniprogram/pages/info/devTeam/devTeam.js` 和 `miniprogram/pages/info/info.js` 仍有 Laf 字样，仓库里没有 Laf 云函数运行目录。公开文档站仍介绍 Laf，仓库主页指向 Sealos。这只说明产品叙述在变化。【未知】laf.run 公有云今天是否仍可新购。本轮没有找到可以引用的官方停购公告，因此不把「已经停购」写成事实。不把它列为首选，是因为微信身份、内容安全和合法域名都要自己接，再加一层平台。若改成自己部署 Laf 或 Sealos，就回到上面的自建条件，而不是一个更轻的托管后端。

**Cloudflare。** 维护者已经接通 Cloudflare。不能把 Cloudflare 写成不可用或未连接。它本轮不列为首选，是项目适配上的条件比较：主用户在国内校园微信小程序里；OpenID 和内容安全要自己接到 Worker 或自建 API 上；国内网络路径、合法域名和备案本轮没有测量。国际账单是否支持银联或其他国内支付，本轮没有核验，标为未知。这些未知项以后若被测量推翻，候选地位可以改，不需要先假定它不可用。

**Supabase。** 同样不因为「海外支付」被写成已淘汰。支付方式本轮未核验。它缺少微信小程序身份的现成集成，国内访问路径也未测。在这两项仍是未知时，不把它放进首选或备选。

## 4. 可复算的费用

金额是人民币元。全部是假设，不是成大的访问统计，也不是账单。每月按 30 天。1GB 按 1024MB。1000 资源点按官方换算等于 1 元。

公共假设：

- 每次访问的图片下行是 8 张 0.25MB 缩略图加 0.2 张 1.5MB 原图，合计 2.3MB。
- 库存里每张照片按 1 张 1.5MB 原图加 1 张 0.25MB 缩略图，合计 1.75MB。这是为了把库存张数换算成 GB，不是实测样张。
- 每次访问读库 20 次、写 0.05 次，调用函数 2 次。函数按 256MB、200 毫秒。
- CDN 命中率按 80% 假设。未命中的 20% 另计回源。
- 不计入：数据库文档容量、存储请求次数、日志、短信、内容安全、函数访问外网拉原图、预置并发，以及每 5 分钟的定时任务。定时任务的真实耗时未知，不能用 60 秒上限乘满一个月当成账单。

三个场景：

| 场景 | 日访问 | 库存照片 | 月下行 GB | 库存 GB |
| --- | ---: | ---: | ---: | ---: |
| 试点 | 50 | 200 | 3.3691 | 0.3418 |
| 常规校园 | 400 | 4,000 | 26.9531 | 6.8359 |
| 增长 | 2,500 | 25,000 | 168.4570 | 42.7246 |

公式：

- 月下行 GB = 日访问 × 30 × 2.3 / 1024
- 库存 GB = 照片张数 × 1.75 / 1024

| 微信基础套餐原价 | 页面写 39 元/月 | 39.00 元/月 | 68.51 元/月 |

把月费乘 12，只表示连续 12 个这样的月份：活动价路径约 238.80 元或增长场景 592.95 元；腾讯云刊例路径约 478.80 元或增长场景 832.95 元。这不是已核实的年付合同价。活动何时结束以购买页为准。微信免费环境在未发布且活动仍有效时可以暂时没有套餐费，发布后约 15 天，不能写成长期 0 元。

路径甲还要另加套餐费，因为 COS 账单不含 CloudBase 月租。路径甲不要再加路径乙的 CDN 点数。路径乙不要再加路径甲的 COS 下行。

自建备选的图片费沿用路径甲。API 和数据库若放在已有服务器上，不在这里再加一台新服务器的月租；那台机器已经在付的续费未知，必须以后加进总成本。从服务器公网直接下发图片的带宽费未知，所以不把「省下 COS」写成省钱。

标准版刊例 199 元/月、330,000 点。增长场景的 69,512 点仍在这个配额里。是否购买这一档取决于回档或其他能力，不取决于本表的点数，也不取决于 60 秒照片预算。

个人新用户 COS 标准存储 50GB、180 天的试用只抵容量，不抵流量。上表三档库存都低于 50GB，试用期内可以减去容量项，流量项保留。试用不是永久免费。

## 5. 结论会随哪些事实改变

| 以后核对到的事实 | 建议如何改 |
| --- | --- |
| 微信基础套餐付费环境可以把超时改到不少于 60 秒，或短任务拆分后验收通过 | 继续把国内付费入门作为实施候选 |
| 付费入门档实际锁在更短超时，而拆分任务的验收也能通过 | 仍可留在入门档，不因此购买 199 元标准版 |
| 你需要官方 14 天回档，并接受 199 元/月刊例 | 仍在 CloudBase 内升到标准版。这不是现在的决定 |
| 服务器规格、续费和接手人都已明确可承受 | 自建可以升为并列或首选，图片仍建议走对象存储 |
| 换届后没有人能登录服务器 | 不把自建当首选 |
| 真实样张使下行倍数明显高于 2.3MB | 两条图片路径的流量费一起上涨。先核对缩略图，而不是换一个后端来假设流量消失 |
| Cloudflare 或 Supabase 的国内访问、微信身份和维护人被实际核验为可接受 | 可以重新打开比较。当前未知项不构成淘汰结论 |
